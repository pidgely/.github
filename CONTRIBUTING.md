# Contributing to Pidgely

Thanks for helping! These guidelines apply to every public repository in the `pidgely` organization.

1. **Open an issue first** for anything larger than a typo, so we can agree on the approach.
2. **Fork and branch** from `main`; keep pull requests focused and small.
3. **Tests**: add or update tests for every change; CI must be green.
4. **Style**: follow the language's formatter and linter configured in the repository.
5. **Commits**: clear, imperative messages (`fix: handle 429 retry-after`).
6. **Security issues** go to security@pidgely.com, never to public issues.

By contributing you agree that your contribution is licensed under the repository's license.
