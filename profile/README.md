### Why Pidgely

- **Drop-in for Resend** — keep your code and SDKs; change the base URL and the API key.
- **Deliverability built in** — per-domain DKIM, aligned SPF, automatic DNS verification, IP warm-up, bounce and complaint handling, one-click unsubscribe.
- **No vendor lock-in** — every message leaves through our own mail servers.
- **Priced for developers** — a free tier and paid plans a fraction of typical email APIs.
